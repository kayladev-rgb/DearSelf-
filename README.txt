DearSelf V38 — PWA

QUICK START (Windows)
1. Extract this folder.
2. Double-click run.bat.
3. The launcher starts a local HTTPS-compatible PWA environment via localhost
   and opens DearSelf in your browser.
4. DearSelf will show an "Install DearSelf?" prompt when the browser makes
   the PWA install option available. You can also use the browser's Install App option.

Important:
- Keep the run.bat window open while using the localhost version.
- This launcher is for local use/testing. It does NOT publish DearSelf to the
  public internet.
- For friends to access the same web app from anywhere, host these files on
  an HTTPS service such as Cloudflare Pages or another static host.
- The PWA stores each person's local app data on their device unless you add
  a shared backend/cloud data system.
